# מאגר השאלות הרשמי

המאגר הרשמי של משרד התחבורה מכיל כ-1,800 שאלות (CC-BY).

## איפה להוריד
1. https://data.gov.il/he/datasets/ministry_of_transport/tqhe  
   (קבצי XML / XLSX)

2. או דרך הדף הדינמי:  
   https://www.gov.il/he/Departments/dynamiccollectors/theoryexamhe_data

## איך להוסיף לפרויקט (בהמשך)
- אפשר להמיר את ה-XLSX לקובץ טקסט פשוט או למערך Java
- בגלל מגבלות זיכרון של נוקיה 205 מומלץ:
  - להתחיל רק עם שאלות לרישיון B (~1,200)
  - או לטעון לפי נושא
  - תמונות תמרורים – רק אם מצמצמים מאוד
