# מבחני תיאוריה לנוקיה 205 (Java MIDlet)

אפליקציה מוגמרת לתרגול ומבחן תיאוריה על **נוקיה 205** (ומכשירי Series 40 / Asha).

- **ניווט:** מקלדת בלבד (חיצים + מקשי תוכנה) – בלי מגע  
- **מאגר:** ~1,800 שאלות רשמיות של משרד התחבורה  
- **מצב תרגול:** כל השאלות  
- **מצב מבחן:** 30 שאלות אקראיות, **40 דקות**, עובר ב־26 נכונות  

## מבנה
```
src/
  TheoryMidlet.java   – האפליקציה
  Question.java
  QuestionBank.java   – טוען מ-res/questions.txt
res/
  questions.txt       – מאגר השאלות (חובה לארוז ב-JAR)
docs/
  BUILD.md
  QUESTIONS.md
```

## בנייה
ראה `docs/BUILD.md`.  
חשוב: קובץ `res/questions.txt` חייב להיכנס ל־JAR בשורש (כ־`/questions.txt`).

## התקנה בנוקיה 205
1. בנה JAR + JAD  
2. העבר לטלפון (Bluetooth / כרטיס זיכרון)  
3. התקן דרך תפריט Java / יישומים
