# מבחני תיאוריה לנוקיה 205 (Java MIDlet)

אפליקציה מוגמרת לתרגול ומבחן תיאוריה על **נוקיה 205**.

## תכונות
- ניווט **מקלדת בלבד** (בלי מגע)
- **תרגול** – כל השאלות במאגר
- **מבחן** – 30 שאלות אקראיות, **טיימר 40 דקות**, עובר ב־26
- **תמונות תמרורים** – כשיש קובץ ב־`/img/` ב־JAR

## מבנה
```
src/          TheoryMidlet, Question, QuestionBank
res/
  questions_*.txt   מאגר שאלות
  img_phone.zip     תמונות מוקטנות לנוקיה (~600KB)
  img/              תמונות אחרי חילוץ
TheoryImages.zip    מקור התמונות המלא (שהעלית)
```

## בנייה
ראה `docs/BUILD.md`.

1. חלץ `res/img_phone.zip` → `res/img/`
2. ארוז ב־JAR: `questions_*.txt` בשורש + `img/*.jpg`
3. יעד: CLDC 1.1 / MIDP 2.0
