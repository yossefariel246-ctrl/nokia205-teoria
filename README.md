# מבחני תיאוריה לנוקיה 205 (Java MIDlet)

אפליקציית Java MIDlet פשוטה לתרגול מבחן תיאוריה (רישיון נהיגה) על נוקיה 205 (ומכשירי Series 40 / Asha דומים).

**מסך:** 320×240  
**פלטפורמה:** MIDP 2.0 / CLDC 1.1  
**שפה:** עברית (RTL)

## מה יש כרגע
- מסך ראשי עם תפריט
- תרגול שאלות (דוגמה עם מספר שאלות לדוגמה)
- בחירת תשובה + משוב נכון/שגוי
- ניקוד בסיסי

## מה עוד צריך (השלבים הבאים)
1. להוסיף את מאגר השאלות המלא ממשרד התחבורה (data.gov.il / gov.il)
2. תמיכה בתמונות תמרורים (אם אפשר במסך הקטן)
3. סינון לפי סוג רישיון (B / A וכו')
4. שמירת התקדמות (RMS)
5. סימולציית מבחן מלאה (30 שאלות, טיימר)

## איך להריץ / לבנות
1. התקן Java ME SDK / Wireless Toolkit / NetBeans עם Java ME plugin
2. פתח את הפרויקט או העתק את קבצי ה-src
3. בנה JAR + JAD
4. העבר את הקבצים לנוקיה 205 (Bluetooth / כרטיס זיכרון) והתקן

## מקור השאלות
השאלות לדוגמה לקוחות מהמאגר הרשמי של משרד התחבורה והבטיחות בדרכים (CC-BY).  
המאגר המלא זמין ב:
- https://www.gov.il/he/Departments/dynamiccollectors/theoryexamhe_data
- https://data.gov.il/he/datasets/ministry_of_transport/tqhe
